# Rosmarium COS v2.1.0

We're excited to announce Rosmarium v2.1.0! This release marks a significant milestone in our V2 Phase 4 (Generative AI Content Studio) roadmap by introducing the **Intelligent Web Ingestion Pipeline**.

## 🎉 New Features

### Intelligent Web Ingestion Pipeline
Rosmarium now includes a fully autonomous, out-of-the-box web crawler and ingestion engine powered by AI. Administrators can now automate content migration and data gathering straight from the web directly into Rosmarium draft entries.

Key capabilities include:
- **Asynchronous Crawling:** Powered by `crawl4ai` and BullMQ, allowing deep, rate-limited, paginated crawling of web targets with automatic Markdown extraction.
- **LLM Content Classification:** Automatically categorizes crawled pages into your existing Rosmarium Content Types based on semantic similarity.
- **LLM Field Mapping:** Uses structured LLM outputs to parse raw markdown into the exact rigid schema fields required by the assigned Content Type.
- **Duplicate Prevention:** Employs hybrid pgvector search and URL tracking to silently ignore pages that have already been ingested, preventing duplicate drafts.
- **Admin Control Center:** A sleek, dual-pane UI in the Admin Dashboard offering robust job configuration (depth, pages, targeting) and real-time streaming logs via Server-Sent Events (SSE).

## 🐛 Bug Fixes & Improvements
- **Server:** Fixed missing test import resolving to `error-test.js` which caused test suite failures.
- **Admin:** Corrected MUI v9 typography prop compatibility warnings.
- **Python Worker:** Improved ruff strictness in ingestion modules.

## 🛠 Upgrading
To upgrade to v2.1.0, pull the latest changes, run the new migrations, and restart your infrastructure:

```bash
pnpm install
pnpm db:migrate
pnpm infra:down && pnpm infra:up
pnpm dev
```
