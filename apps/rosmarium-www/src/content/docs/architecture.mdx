# Architecture

Rosmarium relies on a deliberate split-stack architecture. By using Node.js for I/O bound API tasks and Python for CPU-heavy AI tasks, each layer operates where it is most efficient.

## Event Flow: Content Creation

When a user creates and publishes content, the split-stack orchestrates the intelligence pipeline seamlessly:

<div class="flex items-start gap-4 mb-6 mt-8 not-prose">
  <div class="w-10 h-10 rounded-full bg-neon-cyan/10 border border-neon-cyan flex items-center justify-center text-neon-cyan font-bold flex-shrink-0">1</div>
  <div class="flex-1">
    <h3 class="text-white font-bold text-lg mb-2">Write to Database</h3>
    <p class="text-zinc-400 text-sm"><code>rosmarium-server</code> validates the schema and writes the JSONB entry directly to PostgreSQL.</p>
  </div>
</div>

<div class="flex items-start gap-4 mb-6 not-prose">
  <div class="w-10 h-10 rounded-full bg-neon-cyan/10 border border-neon-cyan flex items-center justify-center text-neon-cyan font-bold flex-shrink-0">2</div>
  <div class="flex-1">
    <h3 class="text-white font-bold text-lg mb-2">Dispatch Job</h3>
    <p class="text-zinc-400 text-sm">An event emitter catches the publish hook and dispatches an <code>embed-content</code> job to the Redis queue.</p>
  </div>
</div>

<div class="flex items-start gap-4 mb-6 not-prose">
  <div class="w-10 h-10 rounded-full bg-neon-purple/10 border border-neon-purple flex items-center justify-center text-neon-purple font-bold flex-shrink-0">3</div>
  <div class="flex-1">
    <h3 class="text-white font-bold text-lg mb-2">Vectorize & Upsert</h3>
    <p class="text-zinc-400 text-sm"><code>rosmarium-ai-worker</code> pulls the job, chunks the text, hits the local Ollama LLM for embeddings, and directly upserts them to <code>pgvector</code>.</p>
  </div>
</div>

<div class="flex items-start gap-4 mb-6 not-prose">
  <div class="w-10 h-10 rounded-full bg-neon-purple/10 border border-neon-purple flex items-center justify-center text-neon-purple font-bold flex-shrink-0">4</div>
  <div class="flex-1">
    <h3 class="text-white font-bold text-lg mb-2">Intelligence Ops</h3>
    <p class="text-zinc-400 text-sm">A secondary <code>analyse-content</code> job is dispatched for NER extraction, auto-tagging, and graph edge generation.</p>
  </div>
</div>
