## The Rosmarium Difference

Most headless CMS platforms were built for the static web, treating AI as a bolt-on plugin. **Rosmarium flips the paradigm.** We treat AI and graph relationships as foundational infrastructure. 

Here is what creates indistinguishable value for enterprise teams running Rosmarium:

## Core Capabilities

> **Hybrid Search by Default**  
> We combine blazing-fast BM25 full-text search with pgvector semantic similarity, fusing the results via Reciprocal Rank Fusion (RRF) for unparalleled accuracy.

> **Visual Workflow Automation**  
> Map out complex organizational publishing rules. Build multi-stage approval chains and schedule content drops seamlessly without writing a line of code.

> **Global Headless APIs**  
> Consume your content exactly how you want. We provide strongly-typed code-first GraphQL (Pothos) alongside lightning-fast REST endpoints, protected by granular API key authentication.
