# Welcome to Rosmarium COS

Most headless CMS tools treat AI as a plugin. Rosmarium treats it as infrastructure, establishing a new paradigm as a Content Orchestration System (COS). A TypeScript/Fastify core handles content, auth, REST/GraphQL, and a knowledge graph layer. A Python/FastAPI worker handles embeddings, RAG pipelines, semantic search, auto-tagging, NER, and graph analytics.

![Rosmarium Hero](../../../../../docs/hero.svg)

## Why Rosmarium?

In an era where unstructured content is fed directly into Large Language Models, traditional keyword search and rigid taxonomy aren't enough. Rosmarium provides:

1. **Hybrid Search**: Blending BM25 full-text and pgvector semantic search using Reciprocal Rank Fusion (RRF).
2. **AI Intelligence**: Automatic Named Entity Recognition (NER), summarization, and zero-shot tagging on publish.
3. **Knowledge Graph**: Automatic typed edges and multi-hop graph traversal.
4. **RAG Pipeline**: Built-in LlamaIndex integration to surface the most contextually relevant chunks.
