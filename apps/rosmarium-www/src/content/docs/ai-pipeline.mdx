# AI Pipeline

The Rosmarium AI Pipeline is driven by a separate Python background worker (`rosmarium-ai-worker`), ensuring that heavy machine learning tasks never block the core Node API.

## Vector Embeddings

Vector embeddings are automatically generated in the background. For the pipeline to trigger, the Content Type must have `aiIntelligence.enabled = true` and the entry must be published.

When these conditions are met, the Node API pushes a job to BullMQ, and the Python worker executes the following:

<div class="flex items-start gap-4 mb-6 mt-8 not-prose">
  <div class="w-10 h-10 rounded-full bg-neon-purple/10 border border-neon-purple flex items-center justify-center text-neon-purple font-bold flex-shrink-0">1</div>
  <div class="flex-1">
    <h3 class="text-white font-bold text-lg mb-2">Chunking</h3>
    <p class="text-zinc-400 text-sm">The text is broken down into semantic chunks using the <code>spaCy</code> sentencizer or our specialized HTML structure chunker.</p>
  </div>
</div>

<div class="flex items-start gap-4 mb-6 not-prose">
  <div class="w-10 h-10 rounded-full bg-neon-purple/10 border border-neon-purple flex items-center justify-center text-neon-purple font-bold flex-shrink-0">2</div>
  <div class="flex-1">
    <h3 class="text-white font-bold text-lg mb-2">Embedding</h3>
    <p class="text-zinc-400 text-sm">The chunks are embedded into high-dimensional vectors using a local <code>Ollama</code> instance running <code>nomic-embed-text</code>, or via OpenAI API.</p>
  </div>
</div>

<div class="flex items-start gap-4 mb-6 not-prose">
  <div class="w-10 h-10 rounded-full bg-neon-purple/10 border border-neon-purple flex items-center justify-center text-neon-purple font-bold flex-shrink-0">3</div>

    <p class="text-zinc-400 text-sm">The resulting vectors are directly upserted back to PostgreSQL utilizing the <code>pgvector</code> extension for blazing fast HNSW indexing.</p>
  </div>
</div>

## Multi-Source Content Ingestion

Rosmarium includes a fully autonomous content ingestion pipeline capable of extracting content from multiple sources and mapping it to your structured Content Types.

Sources supported in v2.1.0+:
- **Web Crawling**: Recursively crawls websites, extracting clean Markdown while respecting rate limits, max depths, and pagination rules.
- **File System**: Ingest local JSON arrays, XML, or raw text files directly from the server.
- **Databases**: Execute SQL or MongoDB queries to import raw database rows into Rosmarium.
- **Cloud Storage**: Ingest files directly from S3 or MinIO buckets.
