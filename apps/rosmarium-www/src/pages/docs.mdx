        <p>Once you've created content through the Admin UI, the Python worker automatically generates semantic embeddings using <code>nomic-embed-text</code> (or OpenAI if configured).</p>
        <p>You can query the unified endpoint which blends keyword and vector scores using Reciprocal Rank Fusion (RRF):</p>
        <pre class="bg-black text-yellow-300 p-4 rounded-lg overflow-x-auto"><code>curl -H 'Authorization: Bearer YOUR_API_KEY' \
  'http://localhost:3000/api/search?q=machine+learning&alpha=0.5'</code></pre>
        <p class="mt-4 text-sm text-zinc-500"><em>Tip: Adjust the <code>alpha</code> parameter. 1.0 is pure vector search, 0.0 is pure full-text search.</em></p>
