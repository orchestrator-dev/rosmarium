# Rosmarium COS v3.0.1

We're excited to announce **Rosmarium COS v3.0.1**! This release marks our verified publication of **V3 Phase 0 (MCP Server & AI Agent Infrastructure)** and synchronizes all packages to version `3.0.1`.

## 🚀 Key Highlights

- **Native MCP Server:** 21 tools and 3 resources enabling AI coding agents to interact with your content repository directly via Stdio transport.
- **Clean CI & Linting Pipeline:** Resolved ESLint and Vitest DOM testing issues across all monorepo packages.
- **Monorepo Version Synchronization:** Updated all 12 Node.js packages and Python AI worker to `3.0.1`.

## 📦 Upgrading to v3.0.1

```bash
git pull origin main
pnpm install
pnpm dev
```
