# Rosmarium Knowledge Graph Setup

This guide shows you how to configure a content type for Graph data modeling, enabling edges and auto-inference of relationships.

## Configuration Schema

Extend your content type settings with the `graph` object.

```json
{
  "graph": {
    "enabled": true,
    "allowedEdgeTypes": [
      {
        "edgeType": "relatedTo",
        "label": "Related",
        "targetContentTypes": ["article", "author"],
        "bidirectional": true
      },
      {
        "edgeType": "deprecates",
        "label": "Deprecates",
        "targetContentTypes": ["article"],
        "bidirectional": false
      }
    ],
    "inferenceStrategies": ["ner", "similarity", "references"],
    "similarityThreshold": 0.85,
    "maxSimilarityEdges": 5
  }
}
```

### Explanation of Fields

- **`enabled`**: If true, this content type participates in the graph. Manual edges and auto-inference can target it.
- **`allowedEdgeTypes`**: Defines valid manual and API-driven edges originating from this content type.
  - **`edgeType`**: The identifier (e.g., `relatedTo`).
  - **`label`**: Human-readable label for Admin UI.
  - **`targetContentTypes`**: An array of allowed target content type slugs. An empty array allows targeting *any* content type.
  - **`bidirectional`**: If true, creating an edge `A -> B` automatically creates the reverse edge `B -> A`.
- **`inferenceStrategies`**: Which automated intelligence pipelines should generate pending edges for this content type.
  - **`ner`**: Creates `mentions` edges between entries that mention the same named entities.
  - **`similarity`**: Creates `relatedTo` edges for semantically similar entries based on vector embeddings.
  - **`references`**: Creates `references` edges by parsing wiki-links (`[[slug]]`) and relative URLs from the content text.
- **`similarityThreshold`**: Minimum cosine similarity (0.0 to 1.0) to generate a similarity edge.
- **`maxSimilarityEdges`**: Limit on how many automatic similarity edges can be generated per entry.

## Admin UI Usage

Navigate to the **🕸️ Graph** tab in the Rosmarium Admin UI.
1. Enter an **Entry ID** to visualize all its relationships.
2. Review **Pending Edges** generated by the AI inference engine. You can accept or reject them with a click.
3. Use the **+ Add Edge** button to manually define relations between entries that AI may have missed.
