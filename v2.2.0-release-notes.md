# Rosmarium COS v2.2.0 Release Notes

Welcome to Rosmarium v2.2.0! This release focuses on strengthening the underlying architecture, dramatically improving code deduplication, and patching critical security vulnerabilities across the monorepo.

## 🔒 Security Enhancements

We take the security of your headless orchestration environment very seriously. In this release, we've closed multiple potential attack vectors:

- **Strict CORS Origin Enforcement**: We removed the overly permissive dynamic `origin: true` configuration in the server. Cross-Origin requests now strictly respect the `CORS_ORIGIN` environment variable, ensuring that only trusted frontend applications can interact with the API.
- **GraphQL DoS Prevention**: To protect against Denial-of-Service attacks via excessively deep and complex queries, we've integrated `@envelop/depth-limit` into Yoga with a maximum depth limit of 10.
- **AI Worker Secret Hardening**: Both the Node.js server and Python FastAPI worker now strictly validate `AI_WORKER_SECRET` on startup. If the environment is set to production, using the default placeholder secret will result in an immediate initialization failure, preventing accidental unprotected deployments.
- **CSRF Mitigations**: Registered `@fastify/csrf-protection` within the server infrastructure to establish baseline defenses against Cross-Site Request Forgery.

## 🏗️ Architectural & Deduplication Improvements

- **Centralized Frontend API Client**: Replaced disjointed ad-hoc `fetch()` calls in the React admin dashboard with a centralized API client SDK. This ensures consistent header injection and unified error handling via a dedicated `ApiError` class.
- **Optimized Content Event Dispatching**: Refactored `rosmariumEvents` listener architecture in the backend. Instead of registering multiple disjointed listeners that repetitively queried the content registry, the system now uses a consolidated dispatcher that enriches the payload exactly once.
- **Shared Domain DTOs**: Migrated core data interfaces (`ContentType`, `FieldDefinition`, `ContentTypeSettings`, `ContentEntry`) into the central `@orchestrator.dev/types` workspace package. Both `rosmarium-admin` and `rosmarium-server` now consume a single source of truth, eliminating repetitive interface declarations.
- **Context-driven Caching**: Introduced `ContentTypeProvider` (React Context) in the admin UI to globally fetch and cache content type definitions, significantly reducing redundant network round-trips to `/api/content-types`.
- **Global FastAPI Router Security**: Applied the `require_worker_secret` dependency at the `APIRouter` level in the AI Worker's search routes, eliminating the need to manually inject the security dependency per-endpoint.

## 📦 Upgrading

Run the following commands to upgrade:
```bash
git pull origin main
pnpm install
pnpm db:migrate
pnpm build
pnpm infra:up
```
