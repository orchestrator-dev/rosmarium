# Rosmarium COS v3.0.0

We're excited to announce **Rosmarium COS v3.0.0**! This major release marks our official entry into **V3 Phase 0 (MCP Server & AI Agent Infrastructure)**, introducing a native **Model Context Protocol (MCP)** server that enables AI assistants, coding agents, and IDEs to directly query, manage, and orchestrate your content repository.

---

## 🎉 New Features

### Native Model Context Protocol (MCP) Server
Rosmarium now includes a built-in MCP server powered by `@modelcontextprotocol/sdk`, communicating over standard I/O (`stdio`). This allows AI assistants like Cursor, Claude Desktop, and Antigravity to seamlessly interact with your headless CMS.

Key capabilities include:
- **21 Specialized AI Agent Tools:**
  - **Content CRUD:** `content_list`, `content_get`, `content_create`, `content_update`, `content_publish`, `content_unpublish`, `content_delete`.
  - **Schema Inspection:** `schema_list`, `schema_get` for dynamic schema discovery.
  - **Semantic & Graph Search:** `search_hybrid` (BM25 + pgvector semantic search) and `search_graph` (knowledge graph edge traversal).
  - **AI Intelligence Layer:** `ai_summarize`, `ai_tag`, `ai_translate`, and `ai_generate` wired directly to our Python/FastAPI AI worker.
  - **Workflow & Scheduling:** `workflow_status`, `workflow_transition`, `workflow_list`, `schedule_publish`, `schedule_cancel`, `schedule_list`.
- **3 Context Priming Resources:** Read-only access to `rosmarium://content-types`, `rosmarium://locales`, and `rosmarium://workflows` for instant workspace context without burning tool calls.
- **MCP Plugin Bridge (G28):** A new extensibility hook allowing third-party plugins to contribute custom MCP tools via `mcpTools` in `@orchestrator.dev/types`.
- **API Key & Tenant Authentication:** Secure execution context handling via `mcpAuth`, supporting `MCP_API_KEY`, `MCP_USER_ID`, and `MCP_TENANT_ID` environment variables.

---

## 🛠 Improvements & Bug Fixes
- **Monorepo Version Bump:** Synchronized all 12 Node.js apps/packages and the Python AI worker to version `3.0.0`.
- **TypeScript Strictness:** Resolved all subpath module resolution errors and Zod typing mismatches across `rosmarium-server`, achieving 0 errors in `tsc --noEmit`.
- **CLI Resolution:** Fixed relative and dynamic import paths in `rosmarium-cli` for reliable command execution.
- **Unit Testing:** Added a comprehensive Vitest test suite (`mcp.test.ts`) covering all 21 tools, resources, and auth workflows with 100% pass rate.

## 📦 Upgrading to v3.0.0
To upgrade to v3.0.0, pull the latest changes, install dependencies, and restart your servers:

```bash
pnpm install
pnpm db:migrate
pnpm build
pnpm dev
```

To test your MCP server from the command line, run:
```bash
npx rosmarium mcp
```
